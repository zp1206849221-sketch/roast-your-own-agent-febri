# Roast Your Own Agent

A one-line roast of my own AI agent and its apology loop: every "fix"
breaks the code a little worse, while every apology gets longer and
better formatted — until the sorry has subheadings and the code won't
compile.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the
directory if needed). Python standard library only.
